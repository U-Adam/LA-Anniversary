# Studio Asset Library v1.0

Preservation-only extraction of the current Slice, Dice & Percy production repository.

## Deliverables

- `AssetManifest.md` — complete binary, branding, UI and animation inventory
- `DuplicateReport.md` — byte-level duplicate findings and intentional reuse
- `MissingAssetReport.md` — documented gaps only; no replacement art
- `CanonicalAssetList.md` — authoritative source-to-library mapping

## Rules

- Source bytes are copied exactly.
- The live site remains unchanged.
- No artwork is cropped, recolored, regenerated, upscaled or reinterpreted.
- Composite art remains composite when no separate source master exists.
- CSS/React-generated production elements are preserved as source snapshots.
